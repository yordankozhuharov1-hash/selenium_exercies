Selenium Exercises 🚀

My first project using Selenium and Python.

Features

- Opens browser automatically
- Performs automated browser actions
- Learning project for Selenium WebDriver
- Written in Python

Installation

Clone the repository:

git clone https://github.com/yordankozhuharov1-hash/selenium_exercies.git

Enter the project folder:

cd selenium_exercies

Install dependencies:

pip install -r requirements.txt

Run the application:

python main.py

Requirements

- Python 3.10+
- Google Chrome or Microsoft Edge
- Selenium

About

This project demonstrates browser automation using Selenium WebDriver. It was created as part of my learning journey in Python automation and testing.
